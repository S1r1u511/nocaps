# Red cap visual trial

`red_cap_center.png` and `red_cap_side.png` are unbranded transparent sprites derived from the three-view red cap art in the older `no-cap-prototype` / `No Cap Landing` projects. The original set has a prominent yellow emblem, so it is not copied into this build.

The Godot cap uses the center view for CENTER, the side view for RIGHT, and a horizontal mirror of the side view for LEFT. This is a temporary readability trial; the final cap representation and art pipeline remain open in the canonical docs.
